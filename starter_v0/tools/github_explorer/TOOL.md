# github_explorer

## Mục đích
Tìm kiếm các repository đang trending hoặc phổ biến nhất trên Github thông qua Github Public API.

## Khi nào dùng
- Khi người dùng hỏi "Có project AI nào đang hot trên Github không?"
- Tra cứu thư viện mã nguồn mở.

## Lưu ý
- Tìm kiếm trả về danh sách repo với tên, sao (stars), fork, và mô tả.
